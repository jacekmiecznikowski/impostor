# Tykająca Bomba – audio

- `bomb-tick.mp3` – przetworzona pod telefon wersja pliku `clock.mp3` dostarczonego przez użytkownika; mono, 32 kb/s, wzmocnione tykanie.
- `bomb-explosion.mp3` – przetworzona pod telefon wersja pliku `explosion.mp3` dostarczonego przez użytkownika; mono, 48 kb/s, lekko obniżony poziom głośności.

Oba pliki są lokalnymi assetami aplikacji i działają offline w APK.
